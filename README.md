# Práctica de ETL con datos de Olist

Archivo para la práctica de almacenes de datos de la materia **Inteligencia de negocios y analítica de datos** (IEST).

`ventas_olist_sucio.csv` es una tabla plana de ventas: una fila por cada producto de un pedido, con los datos del producto, del vendedor y del cliente. Es una muestra de 20,152 filas y **contiene errores sembrados a propósito** (filas duplicadas y en blanco, números guardados como texto, precios inválidos, ciudades mal escritas, valores vacíos) para practicar la limpieza en Power Query.

Enlace directo para el conector *Texto o CSV* de Power BI:

```
https://raw.githubusercontent.com/sanyusbau-iest/practica-olist-powerbi/main/ventas_olist_sucio.csv
```
